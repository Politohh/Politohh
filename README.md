I'm Polito, a video editor making Call of Duty cinematics.

My main project is **Vesper**. I use it to bring maps, characters, and animations into Unreal Engine, where I can light the scene and frame my own shots. With **VesperLiveLink**, I can also record in-game camera moves and character performances for an edit.
